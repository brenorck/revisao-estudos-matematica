# 📚 Revisão de Estudos SESI

Site desenvolvido para auxiliar estudantes do Ensino Médio na revisão dos principais conteúdos escolares.

## 🎓 3º Ano — Matemática

### 📐 Geometria Analítica

Nesta seção são apresentados conteúdos de Geometria Analítica voltados para estudantes do 3º ano do Ensino Médio.

O objetivo é facilitar a revisão dos conceitos por meio de explicações resumidas, fórmulas, exemplos e exercícios interativos.

---

## 📖 Conteúdos

O site aborda os seguintes conteúdos:

- 📍 Plano cartesiano
- 📏 Distância entre dois pontos
- 🎯 Ponto médio
- 📈 Coeficiente angular
- 📐 Equação da reta
- ⭕ Circunferência

---

## 🧠 Quiz

A página conta com um quiz interativo para testar os conhecimentos adquiridos.

O sistema:

- apresenta questões de múltipla escolha;
- identifica a resposta selecionada;
- mostra a resposta correta;
- calcula a quantidade de acertos;
- apresenta a porcentagem de aproveitamento;
- permite refazer o quiz.

---

## ✅ Checklist de estudos

Também foi desenvolvido um checklist para acompanhar os conteúdos já estudados.

O progresso é salvo no navegador utilizando `localStorage`, permitindo que o estudante continue sua revisão sem perder as marcações.

---

## 📊 Barra de progresso

A página possui uma barra de progresso que mostra a porcentagem dos conteúdos já concluídos.

Ela é atualizada automaticamente conforme os itens do checklist são marcados.
